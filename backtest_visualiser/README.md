# Trading Visualiser for Backtests

This is Team Linear Utility's visualiser from Prosperity 2 that i have modified to function with Prosperity 4 
Original Repo: https://github.com/ericcccsliu/imc-prosperity-2?tab=readme-ov-file#round-4%EF%B8%8F%E2%83%A3

**How to Use**

1. Run the following
`python backtest_visualiser_dashapp`

2. Open the app as per the terminal prompt on
`http://127.0.0.1:8050/`

3. Upload Log files to backtest directory then select from logs from drop down menu
