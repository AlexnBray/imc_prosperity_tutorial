# Trading Visualiser for Backtests

This is Team Linear Utility's visualiser from Prosperity 2 that has been modified to function with Prosperity 4 
Original Repo: https://github.com/ericcccsliu/imc-prosperity-2

**How to Use**

1. Run the following
```
python backtest_visualiser_dashapp
```

3. Open the app as per the terminal prompt on
```
http://127.0.0.1:8050/
```

5. Upload Log files to backtest directory then select from logs from drop down menu
